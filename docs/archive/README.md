# Archived collection workflow

`update-news.yml.disabled` is the former AI News Radar / smart-tourism scheduled collection workflow. It is retained only as a source and configuration reference, with the upstream attribution recorded in the repository `NOTICE.md` and `docs/PROJECT_SCOPE_AND_ATTRIBUTION.md`.

The file is deliberately outside `.github/workflows/`, so GitHub Actions does not discover or run it. The current Pages workflow publishes only the Private Intelligence Observatory demo, run workbench, and reading room; it does not publish the archived `data/` or `feeds/` snapshot.
