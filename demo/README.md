# 私人情报所演示站

这是仓库面向使用者的产品入口。它解释私人情报所为什么存在、如何从一个领域关键词开始，以及同一套方法如何先建立领域知识域，再进入文旅、制造、教育和个人专业现场的具体问题。页面中的输入框与示例按钮只切换预设展示结果，不连接真实 AI 环境；实际运行产物请在[运行工作台](workbench.html)中导入查看。

如果要让不会使用 AI 程序的终端用户直接输入领域并生成本地运行，请让安装助手在仓库根目录启动 `uv run --project packages/domain-intelligence private-intelligence`，然后打开 <http://127.0.0.1:8787/>。`local.html` 是本地网站的页面文件；它与静态演示的边界不同，会把真实运行交给核心引擎和公开采集器。

演示站只有一个核心入口：给出一个行业、产业、知识域或细分领域，先把这个领域应有的知识体系与情报体系搭起来。它尤其适合刚进入某个领域、没有知识背景、不知道该看谁和该信谁的人；已有的专家、网站、报告或项目材料，可以在底图建立后直接告诉 AI 加入这个领域。

已经能够独立用 AI 配置信源、搭建日报并维护知识引擎的人，不是本演示站的主要目标用户；工程协作者可以从阅读室和核心引擎进入实现层。

演示站不把任何现成 AI 日报页面或外部 Skill 当成产品主体。页面中的领域、展开结果和人物均为说明方法的静态示例，不代表实时采集结果；真实的领域建立、来源发现、历史回放、覆盖审计和推送，需要在支持核心 Skill 的 AI 工作流中运行核心引擎与用户自己的采集适配器。

当前公开入口是私人情报所演示站、运行工作台与阅读室。仓库中的 AI News Radar 采集脚本、数据和 Skill 仅供边界适配参考，来源与版权见 [../NOTICE.md](../NOTICE.md) 和 [../docs/PROJECT_SCOPE_AND_ATTRIBUTION.md](../docs/PROJECT_SCOPE_AND_ATTRIBUTION.md)。

## 本地预览

在仓库根目录启动静态服务器：

~~~bash
python3 -m http.server 8080
~~~

打开 http://127.0.0.1:8080/demo/；需要管理下一次领域运行、查看当前阶段和真实运行目录中的图谱、来源状态、内容全文与日报时，打开 http://127.0.0.1:8080/demo/workbench.html 并导入运行目录；需要阅读方法、使用场景、工程入口和来源边界时，打开 http://127.0.0.1:8080/demo/reading.html。

## 页面组成

- index.html：页面结构、SEO 元数据、结构化数据和面向使用者的领域优先叙事；
- workbench.html / workbench.js：准备下一次领域运行、查看当前阶段、管理待处理动作，并导入一次真实运行目录查看完整产物链路；
- workbench.css：运行工作台的布局、状态、图谱、内容抽屉和响应式阅读层；
- reading.html：面向使用者与协作者的 HTML 阅读室，不把 Markdown 文件作为演示站的阅读入口；
- styles.css：设计 token、响应式布局、材质、状态和 reduced-motion；
- reading.css：阅读室的长文排版、目录、表格、代码和响应式阅读层；
- app.js：领域示例、关键词输入、预设领域展开和滚动显现；
- assets/：本项目演示站使用的 Hero、工作现场和方法流程视觉资产。
